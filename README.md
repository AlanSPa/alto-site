# ALTO Produtora — site

Site inicial da ALTO Produtora.

## Estrutura

- `index.html` — página principal
- `style.css` — identidade visual e responsividade
- `script.js` — animações discretas
- `assets/logo-alto.png` — logo fornecida
- `whatsapp/index.html` — redirecionamento para o WhatsApp

## Link curto

Depois de publicar no domínio, o endereço:

`https://altoprodutora.com.br/whatsapp`

redireciona para o WhatsApp da ALTO.

## Como adicionar portfólio depois

A seção "EM CONSTRUÇÃO" pode ser substituída por cards de projetos, vídeos incorporados ou páginas individuais. A estrutura foi deixada simples para facilitar futuras alterações.
